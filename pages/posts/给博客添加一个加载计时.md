计时代码
```
/\*\*
\* 加载时间
\* @return bool
\*/
function timer\_start() {
global $timestart;
$mtime = explode( ' ', microtime() );
$timestart = $mtime[1] + $mtime[0];
return true;
}
timer\_start();
function timer\_stop( $display = 0, $precision = 3 ) {
global $timestart, $timeend;
$mtime = explode( ' ', microtime() );
$timeend = $mtime[1] + $mtime[0];
$timetotal = number\_format( $timeend - $timestart, $precision );
$r = $timetotal < 1 ? $timetotal \* 1000 . " ms" : $timetotal . " s";
if ( $display ) {
echo $r;
}
return $r;
}
```
然后是挂载代码
```
- 加载用时php echo timer\_stop();?
```
首先打开handsome模板文件，找到```functions.php```，然后放入计时代码。接着去```post.php```文件中大概31行到45行的位置找到位置并插入即可。
