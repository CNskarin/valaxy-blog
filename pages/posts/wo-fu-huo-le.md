　　大家好，我是 Skarin。时隔多年，我终于重新搭建复活了属于自己的个人博客。

　　最早接触建站和博客，还是在中学阶段。当时凭着对计算机的热爱，经常熬夜折腾各种配置与环境。后来因为站点遭受攻击，腾讯云 CDN 在短短几小时内产生了上千元流量费用，这笔欠费至今还挂在我的腾讯云账号上，也算是早年折腾技术留下的一段有趣经历。

<!-- more -->

## 再次归来

　　多年以后的今天，我终于再次归来。这次我选择使用 GitHub 静态托管部署博客。其实静态博客方案多年前就已经成熟，但配置流程繁琐复杂，一直迟迟没有落地。如今能够顺利搭建完成，很大程度得益于 AI 技术的飞速发展。

　　从 GPT‑3.5 问世开始，我便第一时间体验并注册了 OpenAI，被大语言模型强大的能力深深震撼。短短数年，人工智能完成了跨越式迭代，从简单对话，进化到可以自主处理复杂任务的 AI Agent。

　　以前折腾项目，所有部署、调试、排错都需要自己一步步摸索，现在大量繁琐的技术性工作，我都可以交给 AI 代理完成。本次基于 Valaxy 框架、依托 GitHub 托管搭建的个人博客，全程由 Hermes Agent 协助配置、部署完成，也让我终于实现了多年前的建站想法。

## 为什么是 Valaxy

　　说到这里，可能会好奇我为什么最终选择了 Valaxy。其实我的最初计划，是使用生态非常成熟的 Hexo + GitHub 这套经典组合，这也是很多静态博客使用者的首选。偶然在浏览其他同学的个人博客时，我了解到了 Valaxy 这个还处于开发阶段的项目，新颖的设计理念让我觉得十分有趣。

　　真正促使我下定决心切换技术栈的，是项目官方文档中对于 AI 的原生支持。在大多博客框架还只面向人工操作的时候，它就已经考虑到和 AI 工具协同工作，这一点让我产生了很强的共鸣，刚好契合我现在依赖 Agent 完成大部分工程工作的模式。

　　Valaxy 内置了可供 Agent 直接读取调用的 Skill 能力，很适合交给 AI Agent 去做扩展开发、调试主题、执行部署等一系列操作。既然现在我的工作方式已经习惯让 AI 承担大量重复枯燥的技术环节，那选择一个对 Agent 友好的框架，自然就成了顺理成章的事情，于是我便打算亲身试一试这个框架。

　　如果你能够读到这里，非常感谢你的耐心阅读。接下来我会逐步恢复过去写下的旧文章，同时也会在这里持续更新各类技术相关的内容。欢迎大家一起交流探讨。
